# Курсовой проект по автоматизации тестирования сервиса "Путешествие дня"

## Описание проекта
Данный проект представляет собой автоматизацию тестирования комплексного веб-сервиса, который предлагает купить тур двумя способами:
1. Обычная оплата по дебетовой карте.
2. Выдача кредита по данным банковской карты.

Приложение не обрабатывает данные карт самостоятельно, а пересылает их банковским сервисам (Payment Gate и Credit Gate). Информация об успешности операции сохраняется в СУБД (MySQL).

**Задача:** Автоматизировать позитивные и негативные сценарии покупки тура (UI-тесты + проверка записей в БД).

## Требования для запуска
Для запуска проекта на вашей машине должны быть установлены:
*   **Java JDK 11** или выше
*   **Docker** и **Docker Compose**
*   **Git**
*   Свободные порты: `8080` (SUT), `3306` (MySQL), `9999` (Банковский симулятор)

## Инструкция по запуску

### Шаг 1: Клонирование репозитория
```bash
  git clone https://github.com/Ilich8603/javaAQAmid_aqa-qamid-diplom
 ``` 
```bash
  cd javaAQAmid_aqa-qamid-diplom
```

### Шаг 2: Запуск базы данных (MySQL)
В корне проекта находится файл `docker-compose.yml`. Запустите контейнер с БД:
```bash
  docker-compose up -d
```
*Дождитесь полной инициализации БД (около 10-15 секунд).*

### Шаг 3: Запуск тестируемого приложения (SUT)
Убедитесь, что в файле application.properties указаны корректные данные для подключения к вашей БД (по умолчанию уже настроено на jdbc:mysql://localhost:3306/app, логин app, пароль pass).

Запустите приложение:
```bash
  java -jar artifacts/aqa-shop.jar
```
*Приложение запустится на порту 8080. Не закрывайте этот терминал.*

### Шаг 4: Запуск автотестов
Откройте новый терминал в корне проекта и выполните:
```bash
  ./gradlew clean test
```

### Шаг 5: Генерация и просмотр отчета Allure
После завершения тестов сгенерируйте и откройте отчет:
```bash
  ./gradlew allureServe
```
*Отчет автоматически откроется в вашем браузере.*

## Используемый стек технологий
* Java 11

* Selenide (UI-автоматизация)

* MySQL (СУБД)

* JDBC + DbUtils (проверки в БД)

* Allure (отчетность)

* Docker / Docker Compose (развертывание БД)

* Gradle (сборка проекта)
