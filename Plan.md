# План автоматизации тестирования

## 1. Перечень автоматизируемых сценариев

Все сценарии ориентированы на **заполнение и отправку формы**.

### Предусловия:
 1. Приложение aqa-shop.jar запущено и доступно по адресу http://localhost:8080.
 2. База данных запущена (Docker), доступна, и таблицы payment_entity, credit_request_entity, order_entity очищены от предыдущих записей (для обеспечения независимости тестов).

### Базовые тестовые данные (Валидные)
Используются во всех сценариях, если не указано иное:

* Номер карты (APPROVED): `1111 2222 3333 4444`

* Номер карты (DECLINED): `5555 6666 7777 8888`

* Месяц: Текущий месяц (например, `12`).

* Год: Текущий год + 1 (например, `27`).

* Владелец: Имя и фамилия латиницей через пробел (например, `IVAN IVANOV`).

* CVC/CVV: Три любые цифры (например, `123`).

2. Инструменты:

Selenide/Playwright — для UI-тестов (удобный поиск элементов, автоожидания).

JUnit 5 — для написания и запуска тестов.

Allure — для наглядных отчетов.

Docker — для быстрого развертывания БД.

JDBC — для проверки того, что данные корректно записались в СУБД.

3. Риски:

Нестабильность банковского симулятора (общий сервер на всех студентов).

Сложности с поиском локаторов из-за динамической верстки.

Задержки при записи в БД (нужны явные ожидания).

4. Оценка по времени (в часах):

Изучение SUT и ручное тестирование: 4-6 ч.

Настройка проекта (Gradle, зависимости): 2-3 ч.

Написание UI-тестов: 10-12 ч.

Написание DB-тестов: 4-6 ч.

Оформление отчетов (Report.md, Summary.md) и Issues: 4-6 ч.

Итого: ~24-30 часов.
